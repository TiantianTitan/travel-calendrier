# 移动体验依据

品牌为“图图小分队三日游”，Logo 使用有明确公有领域或 CC0 依据的图卢兹风景图，[原图与 CC0 许可](places-extra-sources.md#可用于图标的-cc0-风景照片)可查。界面采用白底、浅灰统一组件，去除渐变、阴影、多色日期与手绘装饰。首页移除旅行简介块，直接呈现行程与景点。文案保留具体事项和直接动作，错误、冲突比较、候选标记与必要确认继续显示。

- **触控与滚动**：拖动限定在手柄，正文保留正常滚动；用 `touch-action` 预先声明手势区域，避免依赖根级触摸事件阻止滚动。这一取舍参考 [Chrome 的触控滚动说明](https://developer.chrome.com/blog/scrolling-intervention)。
- **动效**：本项目采用功能性、少回弹的方向，参考 Google Material 的 standard motion；不因此引入整套弹簧系统或装饰动画。[Material motion](https://m3.material.io/styles/motion/overview/how-it-works)
- **动画性能与可访问性**：过渡优先使用 `transform` / `opacity`，避免动画反复触发布局；遵循 `prefers-reduced-motion`，减少非必要运动。它们是实现原则，不是已测帧率结论。[动画性能](https://web.dev/articles/animations-guide)、[减少动态效果](https://web.dev/articles/prefers-reduced-motion)
- **地图**：地址用 `https://www.google.com/maps/search/?api=1&query=...`，编码当前地址并补充城市。Maps URLs 不需要 API key，按设备环境打开地图应用或网页。[Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)

真实景点目录可持续扩展，不固定条目上限。点击景点先打开介绍弹窗，展示 4–8 张不同实景照片、简短简介、地址和按所选行程日核实的官方开放信息；仅查看或关闭介绍不会创建活动。点“添加活动”后才进入预填的可编辑表单，保存才创建；介绍与表单接续而不叠加多层模态，草稿按景点和日期隔离。开放资料在介绍和表单中都随所选日期切换；编辑活动时按当前地址恢复关联，更换地址后不保留旧景点信息。开放信息仅作独立参考，不写入活动备注或冒充活动实际起止。照片来源、许可、地址及开放资料核实记录见 [首批景点资料](place-sources.md)、[新增景点资料](places-extra-sources.md)、[更多景点资料](places-more-sources.md)和[补充图库](places-gallery-sources.md)。

五个角色保留稳定 ID，初始昵称为 Hoting、Mia、James、Ganggang、Kada。共享昵称和表情头像保存后同步到角色入口、活动头像和参与名单，已有接龙和点赞仍绑定原 ID。头像可使用昵称首字或预设表情，不提供照片上传入口。保存前取消不提交，旧请求结果不能影响后来打开的编辑会话。不同资料字段可合并，同字段冲突保留草稿并提供最新资料比较；结果不确定时复用原请求重试，退出面板不等于撤销已发出的保存。昵称与头像是共享资料，角色选择不承担身份认证。

活动互斥按直接重叠判断：同日、两项结束均晚于开始，且 `a.start < b.end && b.start < a.end`。边界相接、跨日、无结束或零时长不猜测冲突。展示可按重叠连通关系集中，但仅当组内任意两项都相交时标“N 选 1”；否则标“部分重叠”，用时间条说明关系并保留每项时间。A 14:00–15:00、B 14:30–16:00、C 15:30–17:00 允许同成员参加 A+C，确认 B 时才需撤回 A+C。

切换确认列明本人所有直接冲突的已参加活动；确认后一次原子更新，其他成员、感兴趣和考虑考虑均保留。确认期间目标时段或冲突集合变化时拒绝旧确认，避免静默撤回未审阅的选择；移动或延长已有参加活动造成同成员重叠时，也保留原状态并提示调整。技术上的 `choiceKey` 仍记录目标日期与起止时间快照，不能拿它的相等关系代替重叠判断；`previousIds` 记录直接冲突的已参加活动集合，详见 [数据库规则](database.md)。

本轮使用桌面浏览器工具检查，尚未进行 iOS Safari / Android Chrome 真机验证。手机尺寸模拟和截图不能证明真机触感、软键盘行为、浏览器栏伸缩或帧率；这些项目，以及旋转、安全区、后台恢复和地图应用跳转，仍需在实际设备复核。

## 全局动效复查（2026-10-30）

- 小按钮保留 100 ms 按压反馈；标题、整张景点卡和宽列表项采用颜色/透明度变化，避免大块内容和文字缩放。状态与边框使用 140 ms 过渡，地图入口也有按下反馈。
- 日期选中块用 170 ms 位移提示方向，用户换日仅对当前内容做 130 ms 淡入。每一天保留阅读位置；首次进入另一日从当前视野或行程入口开始，不跳回景点顶部；快速换日取消上一帧的滚动恢复。远端实时更新不触发这段动效。
- 用户关闭、Escape、点遮罩和取消共用 140 ms 退出；期间保留原模态、焦点与遮罩，表单不可提交。动画结束或备用计时器只完成一次关闭，卸载清理计时器；业务保存成功和详情接续仍立即切换。返回焦点继承弹窗入口链，旧面板不会抢新面板的焦点。
- 相册连续按下一张按目标累计，反向与手动滚动可接管；滚动读取按帧合并，尺寸改变时重新测量。新照片短暂淡入，已缓存图片直接显示，照片占位尺寸不变。
- CSS 动画与 JS 日期、相册、拖放动画均读取系统“减少动态效果”。JS 媒体偏好通过 [React 的外部状态订阅](https://react.dev/reference/react/useSyncExternalStore)响应更新；模态的挂载与焦点沿用 [Radix Dialog](https://www.radix-ui.com/primitives/docs/guides/animation)，父级条件卸载的场景单独管理用户退出阶段。

浏览器验收覆盖桌面及 390 CSS px：弹窗退出期间 `inert`、关闭后无遗留遮罩/锁定、详情→编辑→取消的焦点返回、相册连续前进三次到第 4 张和反向两次到第 2 张、缓存封面正常显示、日期指示条与各日阅读位置恢复、无页面横向溢出。没有写入或删除共享行程数据；未进行真机帧率测试或系统偏好切换实测。
